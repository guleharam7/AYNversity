# AYNversity — Database

**Database:** MongoDB  
**Name:** `AYNversityDB`  
**Collections:** `Users`, `Courses`

---

## Collections

### Users

| Field      | Type   | Notes                              |
|------------|--------|------------------------------------|
| `_id`      | ObjectId | Auto-generated by MongoDB         |
| `Name`     | String | Full name                          |
| `Email`    | String | Unique, lowercase                  |
| `Password` | String | BCrypt hashed                      |
| `Role`     | String | `"Student"` \| `"Teacher"` \| `"Admin"` |

### Courses

| Field           | Type       | Notes                        |
|-----------------|------------|------------------------------|
| `_id`           | ObjectId   | Auto-generated               |
| `Title`         | String     | Required                     |
| `Description`   | String     | Required                     |
| `Category`      | String     | e.g. Web Development         |
| `Instructor`    | String     | Display name                 |
| `UserEmail`     | String     | Teacher's email (owner)      |
| `NotesUrl`      | String     | Optional URL or upload path  |
| `VideoUrl`      | String     | Optional URL or upload path  |
| `EnrolledUsers` | String[]   | List of enrolled student emails |

---

## How to Seed

### Option 1 — mongosh (terminal)
```bash
mongosh < seed.js
```

### Option 2 — MongoDB Compass
1. Open Compass → connect to your MongoDB
2. Open **MongoShell** (bottom bar)
3. Paste the contents of `seed.js` and press Enter

### Option 3 — MongoDB Atlas
1. Go to your cluster → **Collections**
2. Use **Insert Document** to manually add from `seed.js`
